# Автономное управление телефоном голосом

Версия 0.42.0 добавляет прямое локальное управление без запроса к серверу или LLM.
Распознавание и озвучка по-прежнему работают на телефоне. При первом запуске этой
версии режим ответов один раз переключается на LOCAL; последующий явный выбор
другого режима сохраняется. Голосовая команда «автономный режим» также сохраняет
LOCAL между разговорами. Это режим диалога, а не отключение Wi-Fi/мобильных данных
и не глобальная блокировка фоновой синхронизации/OTA.

## Команды

| Скажите | Что выполняется |
| --- | --- |
| «назад», «домой», «сверни приложение» | Системная навигация через AccessibilityService |
| «последние приложения» | Системный список недавних приложений |
| «открой шторку», «быстрые настройки», «закрой шторку» | Панели SystemUI через публичные global actions |
| «заблокируй телефон» | Системная блокировка; команда не умеет обходить PIN/пароль |
| «сделай скриншот» | Запрос системного снимка. Успех API означает принятие запроса, не подтверждение сохранённого файла |
| «открой меню питания» | Открывает системное меню, не выключает/перезагружает сам |
| «громкость пятьдесят процентов», «громче», «тише» | Громкость потока музыки, с фактическим считыванием результата. Шаги устройства могут округлять процент |
| «яркость семьдесят» | Ручная яркость; автоматическая яркость отключается. Читается записанное значение |
| «включи фонарик», «выключи фонарик» | CameraManager torch с подтверждением callback и таймаутом; не съёмка камерой |
| «открой настройки вайфая/блютуза/интернета/экрана/звука/геолокации/батареи» | Публичный системный раздел. Открытие раздела не означает изменение переключателя |
| «кнопки на экране» | До десяти доступных кнопок текущего окна по номерам, включая активную панель SystemUI |
| «второй», «номер три», «10» | Выбор из предложенного списка; нажатие кнопки ещё подтверждается |
| «нажми Название», «введи Текст», «прочитай экран», «прокрути вниз/вверх» | Существующие команды Accessibility и локального OCR |
| «открой», «позвони», «напиши», «нажми», «измени громкость», «яркость» | Ассистент голосом спрашивает недостающий аргумент; следующий ответ дополняет команду |
| «да», «нет», «отмена», «стоп» | Подтверждение, отмена или остановка; не подменяются догадкой модели |
| «повтори», «что ты услышал», «команды телефона» | Повтор последнего ответа, последней команды и краткая голосовая помощь |

Пример: «открой» → «Какое приложение открыть?» → «спотифай».
Пример: «измени громкость» → вопрос о проценте → «пятьдесят».
Пример: «кнопки на экране» → «второй» → описание выбранной кнопки → «да».
Уточнения действуют до 60 секунд; подтверждение выбранного нажатия — до 30 секунд.
Если экран изменился, старый target не используется: нужно перечитать кнопки.
Название окна, координаты и номера берутся из Accessibility текущего экрана;
они не выдумываются по тексту запроса. Парольные узлы исключены.

## Первичная настройка

В «Настройки → Доступы»:

- микрофон и Bluetooth — для голосового разговора/гарнитуры;
- доступ к экрану — для глобальных действий, чтения и нажатий;
- изменение системных настроек — только для яркости;
- камера — только для Android API фонарика;
- контакты/звонки и уведомления — по необходимости соответствующих команд.

Системные разрешения выдаются пользователем в интерфейсе Android. Приложение не
назначает их скрытно. Фонарик недоступен на устройствах без вспышки или при занятой
камере; системные действия могут отсутствовать в текущем getSystemActions().
На заблокированном телефоне навигация/чтение закрыты; громкость, яркость и фонарик
не открывают частные данные и доступны при имеющихся разрешениях.

## Границы автономности

Прямым командам, уточнениям и списку кнопок не нужна LLM. Для произвольной сложной
задачи «выполни задачу …» нужна импортированная совместимая локальная GGUF-модель.
Существующий планировщик делает ограниченные шаги, проверяет экран и запрашивает
подтверждения нажатий/ввода; это не гарантия выполнения любой задачи в любом UI.
Защищённые окна, PIN, ограничения API и разрешения Android не обходятся.

Свежая погода, поиск по сети, передача сообщения через интернет и онлайн-контент
других приложений без сети не появятся. Открыть Spotify можно локально; его
доступность музыки без интернета зависит от сохранённых треков и самого Spotify.
LOCAL исключает автоматическую отправку сложных запросов Hermes, но отдельные
явно вызванные сетевые инструменты и настроенные фоновые сервисы остаются
самостоятельными функциями. Не называй этот режим полным запретом сетевого трафика.

## Код и проверка

- `PhoneCommands.kt`: строгая грамматика полных команд, проценты, вопросы по слотам.
- `PhoneControl.kt`: публичные Android API, проверка доступности/результата.
- `VoiceConversation.kt`: уточнения, повтор, сохранение режима, единый голосовой цикл.
- `DeviceTools.kt`, `PhoneAccessibility.kt`: номера кнопок, snapshot и подтверждение.
- `PhoneCommandsTest`: маршрутизация, диапазоны, буквальный диктуемый текст.
- `OfflinePhoneControlTest`: эмулятор с выключенными Wi-Fi/mobile data, текстовые
  синтетические команды, реальная системная навигация и защита от устаревшего UI.

Проверки запускаются только на явно выбранном отдельном эмуляторе, с `-no-audio`,
без реального микрофона и без управления пользовательским телефоном. Перед
изменением значений в тестах запоминай и восстанавливай исходное состояние.
Инструкции и правила устройства из корневого AGENTS.md сохраняются.
