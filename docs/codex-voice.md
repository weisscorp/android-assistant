# Codex через Hub

С версии 0.35.0 прямые голосовые и текстовые команды не загружают локальную LLM:

- «Задачи кодекса».
- «Выбери задачу кодекса» и название из списка.
- «Статус кодекса».
- «Прочитай отчёт кодекса».
- «Передай кодексу» и текст продолжения.

В настройках подключения укажите адрес Hub и ключ владельца. На компьютере
включите нативный мост Codex: [настройка Hub](https://github.com/weisscorp/assistant-hub/blob/main/docs/codex-voice.md).
Выбор сохраняется в Hub для идентификатора телефона и текущей темы. При
неоднозначном названии Hub уточняет задачу; без выбранной задачи сообщение
не отправляется. Полученные отчёты не могут сами запускать команды.

Hub принимает сообщение в очередь и продолжает конкретный нативный чат; телефон
озвучивает принятие, а итог приходит отдельно через существующую домашнюю ленту
событий. «Прочитай последнее сообщение от гермеса» читает последнюю запись этой
ленты, включая событие Codex. Для полного нативного отчёта используйте команду
«прочитай отчёт кодекса».

Запросы используют тот же HTTPS-транспорт, сохранённый ключ и проверку сертификата.
Ключ только для вебхуков не подходит для голосового управления. Сетевая отмена
на телефоне не отменяет уже принятую задачу Codex. При потере ответа приложение
не повторяет отправку автоматически: проверяйте состояние задачи.

Оповещения не запускают микрофон и не озвучиваются автоматически. Работа
гарнитуры, распознавания и голоса сохраняется в существующем голосовом тракте.
