# Contributing

Use neutral synthetic examples and respect Android permission boundaries. Do not
hardcode an owner's contacts, school, chat, site or private server into the product.
Store such configuration as user knowledge. Preserve third-party notices and
model terms. Keep Hub coordination in the companion Hub repository and Android
device execution here; document protocol changes on both sides.

Run JVM and dependency-preparation tests relevant to your change. Measure voice
or model runtime on an appropriate ARM64 runtime and state which environment was
used. Never equate emulator timings with phone performance. Do not use attached
physical devices or install/update APKs automatically during development or CI.
